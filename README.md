# 🌐 Personal Portfolio Website  

A modern and responsive **personal portfolio website** built with **React.js** and **Tailwind CSS**, featuring smooth UI design and seamless **contact form submission using Getform**.  

---

## 🚀 Features  

- 🎨 **Modern UI/UX** with Tailwind CSS styling  
- 📱 **Fully Responsive Design** (mobile, tablet, desktop)  
- 👤 **About Me Section** showcasing skills  
- 💼 **Projects Showcase** with live links and GitHub repos  
- 📧 **Contact Form Integration** using **Getform** for form submissions  
- ⚡ **Fast and Optimized Performance** with React.js  

---

## 🛠️ Tech Stack  

**Frontend**  
- React.js  
- Tailwind CSS  

**Form Handling**  
- Getform (for contact form submissions)
